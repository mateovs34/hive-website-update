Abriste el archivo directo — el chat no va a funcionar

El browser bloquea requests a APIs externas cuando la página corre desde file://. Servila desde un servidor local: en la terminal, dentro de la carpeta del archivo, corré npx serve . o python3 -m http.server y abrí http://localhost:3000 (o el puerto que indique).

⚠️
Demo con proxy local — API key segura en el servidor

El widget llama a localhost:3001/chat. El proxy (proxy.js) maneja la API key. Para correr: OPENAI_API_KEY=sk-... node proxy.js y servir la carpeta con npx serve .
